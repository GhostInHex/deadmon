How it works

Three verdicts, never a guess.

Aggregators list dead deadlines as if they were live. deadmon refuses to guess. Every listing earns exactly one verdict, and anything it cannot prove stays visible rather than being quietly dropped.

live
Source responded, the registration close parses to a real future date in a known timezone, and a mode was stated.
unverified
We could not find out. Blocked, unreachable, or an unreadable date. Re-checked next crawl, never cached as fact.
closed
Registration has passed or the event was cancelled. Terminal, keeps its row, and leaves the feed.

Evidence

Every run is a trace.

Each crawl run produces one trace with per-stage spans, linked from the run history. When a platform changes its layout, the agent diagnoses the break from the failing run and repairs its own adapter.
