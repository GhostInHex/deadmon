# known-limits.md — honest limits

What deadmon cannot do today, stated so a judge never has to guess.

## Platforms

- **Devfolio has no usable data path.** The grid is client-rendered; the
  recorded pages hold placeholders, and every probed API shape returns
  422. No adapter without a data path. Options are recorded in
  `fixtures/README.md`.
- **Devpost returns 403** to scripted requests. Unknown until measured,
  not available.
- **Unstop `unverified` is unrecordable.** Every record sampled carries a
  usable ISO-8601 close, so the third verdict is exercised by a declared
  test double, named as one wherever it appears — never mistaken for
  recorded evidence.

## The demo heal is staged

- heal-001's changed-layout snapshot is **constructed, not recorded**:
  Unstop did not change its layout overnight. It declares this in its own
  contents, its filename, its provenance row, and the evidence README.
- The proposal stays a demo double. The real adapter is unchanged —
  production code never changes for a staged break.
- The loop is proven as recorded evidence, not a running service:
  detection ships (the watchdog); proposal generation, commit, and
  scheduled backfill are Slice 4 work.

## Costs and plans are modelled, not measured

- `$0.00/crawl stdlib-only` is modelled: no model calls exist on the crawl
  path, but no production bill has been observed either.
- `docs/business-plan.md` is a proposed plan, explicitly not observed
  financial performance. Tiers are a draft, never traction.

## Quiet is not broken — and not yet baselined per crawler

- MLH off-season zero is steady state, not a break. The watchdog fires on
  two consecutive zero-listing runs; the rolling per-crawler baseline
  record of ADR-0011 is not yet stored — that is Slice 4 work.

## Verification assumes the fixture

- A future close in a recorded fixture proves the pipeline, not that the
  source page is still live. Live re-verification against real pages is
  future work; the suite stays offline by design.
